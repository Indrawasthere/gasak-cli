# Fix install.sh + Runtime Guards di GASAK Binary

## Problem
Ketika device punya broken APT dependencies atau broken repo, `install.sh` gagal karena:
1. `sudo dpkg --configure -a` bisa hang atau error fatal
2. `sudo apt-get install -f -y` bisa trigger interaktif prompts
3. Beberapa command APT tidak punya `|| true` protection

## Solution
Buat APT handling benar-benar bulletproof:
1. Detect apakah `sudo` available
2. Detect apakah APT available & working
3. Skip APT entirely kalau broken, jangan coba-coba repair
4. Install Python manual kalau APT gagal

## Changes

### 1. Detect APT status di awal (sebelum dpkg/apt-get)
Tambah function `apt_is_broken()` yang return true kalau:
- `dpkg --audit` gagal
- `apt-get update` gagal

### 2. Bungkus semua APT commands dengan protection
```bash
# BEFORE (bermasalah):
sudo dpkg --configure -a 2>/dev/null || true
sudo apt-get install -f -y 2>/dev/null || true

# AFTER (bulletproof):
sudo dpkg --configure -a 2>/dev/null || warn "dpkg configure failed, skip"
sudo apt-get install -f -y 2>/dev/null || warn "apt-get -f failed, skip"
```

### 3. Add APT detection gate
Kalau `apt_is_broken()` return true, langsung skip seluruh APT section dan kasih warning ke user.

### 4. Python fallback kalau APT gagal
Kalau APT broken tapi user udah punya Python 3.8+, skip aja APT install dan lanjut ke pip install.

### 5. Remove sudo timeout hang risk
`sudo dpkg --configure -a` bisa hang kalau ada broken package. Tambah timeout:
```bash
timeout 30 sudo dpkg --configure -a 2>/dev/null || warn "dpkg configure timeout/failed"
```

## Files
- `install.sh` — APT best-effort (coba install walau update gagal, karena package mungkin udah di cache)
- `main.go` — tambah runtime guard sebelum menu yang butuh sshpass/tkinter

## install.sh Changes
1. Ubah `APT_BROKEN` jadi `APT_UPDATE_OK` — kalau update gagal, **TETAP coba install** (package mungkin di local cache)
2. Hapus logic skip semua APT kalau broken
3. Tambah timeout 60s per package install
4. Kalau install gagal juga → skip package itu, jangan abort

## main.go Changes — Runtime Guards

### Tambah helper functions (sekitar line 1350):
```go
func commandExists(name string) bool {
    _, err := exec.LookPath(name)
    return err == nil
}

func checkSSHPass() bool {
    return commandExists("sshpass")
}

func checkPythonTk() bool {
    cmd := exec.Command("python3", "-c", "import tkinter")
    return cmd.Run() == nil
}
```

### Tambah guard di switch statement (sekitar line 488-520):
```go
case "parkee_launcher":
    if !checkSSHPass() {
        logErr("sshpass tidak terinstall.")
        logInfo("Jalankan: sudo apt-get install sshpass")
        break
    }
    runParkeeLauncher()
case "location_lookup":
    if !checkSSHPass() {
```

## Key Insight
APT update gagal ≠ APT install gagal. Package mungkin udah ada di local cache. Jadi tetap coba install per-package walau APT update gagal.
